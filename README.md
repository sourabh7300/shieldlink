# 🛡️ Shieldlink

> Short links with seatbelts: password protection and expiry, entirely client-side.

**🔴 Live demo:** https://sourabh7300.github.io/shieldlink/

## What it does
- Snip long URLs into short codes (custom codes supported)
- Optional password gate before a link opens
- Set expiry so links die when you want them to
- No accounts, no server database — everything computed in the browser

## Built with
HTML · CSS · JavaScript — **zero frameworks**, single file, runs in any browser.
